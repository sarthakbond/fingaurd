Technology

The analysis runs where the file already is.

FinGuard's pipeline is local-first: frame extraction, visual and audio forensics, transcription, compliance reasoning, and registry matching all execute on the machine running the service. Uploaded media is written to an isolated per-job directory and deleted when the job ends, whether it succeeded or failed.
